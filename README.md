# Quiz de conhecimentos gerais

Um quiz interativo de cinco perguntas, feito com HTML, CSS e JavaScript puro.

## Funcionalidades

- Exibir perguntas com alternativas
- Informar se a resposta está correta
- Acompanhar progresso e pontuação
- Mostrar o resultado e permitir jogar novamente

## Como executar

Abra `index.html` em um navegador. Não é necessário instalar dependências.
